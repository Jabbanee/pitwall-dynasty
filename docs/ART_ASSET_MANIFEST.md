This manifest lists every visual asset used in the UI, where it
lives, what generates it, and the licence/safety status. Anything
listed here is safe to distribute. Real-world / copyrighted
material is explicitly excluded.

## Asset rules

- Do not import images from third parties.
- Do not reference real team, driver, sponsor or championship
  trademarks anywhere in the project.
- All visual additions must be added to this manifest.
- Asset path conventions:
  - `src/ui/three/` for the WebGL broadcast assets
  - `src/ui/icons.ts` for the inline SVG icon set
  - inline `<svg>` blocks in component files for one-off decoration
- Asset safety checks are part of the PR review.
